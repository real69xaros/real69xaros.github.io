# XIS AntiCheat

> Server-authoritative anticheat for Roblox.<br>74 detectors, one file to tune them.

- **Drop-in install** — no changes to your existing systems
- **Server adjudication** — a lying client can't get anyone kicked
- **Whitelist API** — for when your own systems break the rules
- **One master switch** — stop enforcing without stopping the logging
